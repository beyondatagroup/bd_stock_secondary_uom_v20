Overview

Stock Secondary Unit of Measure

The Stock Secondary Unit of Measure module extends Odoo Inventory to manage product quantities in both the primary and secondary Units of Measure. It automatically retrieves the configured Secondary UoM and converts quantities across inventory movements, receipts, deliveries, internal transfers, stock levels, and scrap operations.

Configuration

1. User Access Rights

  • Before using the Secondary Unit of Measure features, assign the appropriate access group to the users.

  • Navigate to Settings → Users & Companies → Users

  • Open the required user and configure the following access groups.

Secondary Unit on Product

  • Assign the Secondary Unit on Product group to users who need to configure Secondary Unit of Measure on products.

  • This allows users to access the Secondary Unit configuration available on the Product form.

Secondary Unit on Inventory

  • Assign the Secondary Unit on Inventory group to users who need to use Secondary Unit information in Inventory operations.

  • Users assigned to this group can access Secondary Unit information in Inventory operations, including: Secondary UoM , Secondary Quantity, Secondary Done Quantity, Secondary Quantity in Scrap

  • Users without this access group will not see these additional Secondary Unit fields.

Users Requiring Both Features

  • For users who need to configure the Secondary Unit on products as well as use it in Inventory operations, assign both access groups:Secondary Unit on Product and Secondary Unit on Inventory operations

2. Enable Units of Measure

  • After configuring user access, enable Odoo's standard Units of Measure functionality.

  • Navigate to Inventory → Configuration → Settings

  • Enable Units of Measure & Packagings and save the configuration.

3. Configure Secondary Unit on Product

  • Go to Inventory → Products → Products

  • Open the required product.

  • On the Product form, enable Use Secondary Unit and select the required Secondary Unit of Measure.

4. Automatic Secondary UoM in Inventory Operations

  • Create or open an Inventory Transfer.

  • Navigate to Inventory → Operations → Transfers

  • Create a: Receipt , Delivery Order , Internal Transfer

  • When a product with Secondary Unit configuration is selected, the system automatically fetches the product's configured Secondary UoM.

  • Users can see: Quantity , Unit of Measure, Secondary UoM, Secondary Qty, Secondary Done Qty

5. Automatic Secondary Quantity Calculation

  • Once the Secondary UoM is configured, the system automatically calculates the equivalent quantity based on Odoo's standard UoM conversion.

6. Secondary Done Quantity

  • The module also calculates the actual completed quantity in the Secondary UoM.

  • When the Done Quantity is updated, the system automatically calculates the corresponding Secondary Done Qty.

  • This helps users track both planned and completed quantities in secondary units.

7. On-Hand Stock

  • The module extends the Inventory On-Hand quantity view with Secondary Unit information.

  • Navigate to Inventory → Operations → Physical Inventory

  • The stock quantity can be viewed along with Secondary Qty and Secondary UoM.

  • The Secondary Qty represents the available On-Hand quantity converted into the product's configured Secondary UoM.

8. Scrap Management

  • The Secondary Unit functionality is also available in Scrap operations.

  • Navigate to Inventory → Operations → Scrap

  • Select the product and enter the Scrap Quantity.

  • The system automatically displays Secondary Qty and Secondary UoM

  • The Secondary Quantity is calculated based on the Scrap Quantity and the configured Secondary UoM.
  • This allows vendors and internal users to clearly understand the ordered quantity in both the primary and secondary units.

9. Inventory Transfer Report

  • The module extends the Inventory Transfer/Delivery report to display the Secondary Quantity.

  • When the transfer document is printed, users can see the Secondary Quantity along with the standard quantity.

  • This provides clear visibility of stock movement in both primary and secondary units.

10. Secondary Unit in Detailed Operations

  • For tracked products and detailed stock move lines, the module also provides Secondary information.

  • Users can view Secondary Qty and Secondary UoM in the detailed operation lines.
